# Fund Manager Time Machine 基金經理時光機

A solo classroom game for *Financial Market and Global Business* (Fu Jen Catholic University).
Allocate ◎1,000,000 across stocks, Bitcoin, bonds, gold and cash on 8 real dates from 2020 to 2025.
English by default, with a 中文 toggle. Learning game, not investment advice.

Open `index.html` in a browser, or use the GitHub Pages link of this repo.
